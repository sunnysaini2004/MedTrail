# MediTrail

**A Digital Patient Medical Record and Referral Management System**

Tagline: *One Patient. One Connected Treatment Journey.*

## Project status

This repository is currently a starter scaffold. The frontend, backend, and database implementation will be added step by step.

## Planned stack

- Frontend: React, Vite, Tailwind CSS, React Router
- Backend: Node.js, Express.js, REST APIs
- Database: MySQL 8
- Database driver: mysql2
- Version control: Git and GitHub

## Planned structure

- `client/` — React frontend
- `server/` — Express backend
- `database/` — database migrations and seed data
- `docs/` — requirements, architecture, API specification, and testing notes

## Important safety note

Use synthetic demo patient data only. Do not store real patient data, credentials, API tokens, or database passwords in this repository.

## Setup

Setup instructions will be added as each development phase is completed.
